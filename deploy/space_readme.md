# SoilSight

Take a phone photo of soil and get the soil type, how sure the model is, and the grain size curve.
DES400 project. Source code: https://github.com/JayVarMEs/soilsight-mockup

Photos are analysed in memory and not stored on the server. History is kept only in your own browser.
